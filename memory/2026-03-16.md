### Motion.dev Research (User Request)
- User wants to integrate "Framer Motion and Framer MCP" to make site less like "AI slop"
- **Motion.dev** (formerly Framer Motion) now works as standalone vanilla JS — no React needed
- Can include via CDN: `<script src="https://cdn.jsdelivr.net/npm/motion@latest/dist/motion.js"></script>`
- Key capabilities: spring physics, scroll-linked animations (5.1kb), gesture animations, stagger/orchestration, layout animations
- **Framer MCP** is for Framer's design platform (framer.com hosted sites) — NOT applicable to our standalone HTML site
- Recommended: Use Motion.dev vanilla JS directly, skip Framer MCP
